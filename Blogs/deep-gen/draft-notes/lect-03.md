# Demystifying Machine Learning: Probability, Prediction, and the Core of Generative Modeling

In the study of modern artificial intelligence, we often find ourselves caught up in the mechanics of training neural networks, tuning hyperparameters, and scaling up compute. However, at its core, machine learning is an exercise in applied probability and statistics. 

These lecture notes lay down the mathematical foundations of machine learning problems. We will bridge the gap between abstract probability theory and the practical objectives of discriminative (supervised) and generative (unsupervised) modeling.

---

## 1. The Foundation: A Quick Recall of Probability Theory

Before defining what it means to "learn" from data, we must establish the mathematical universe in which our data lives. Recall from measure-theoretic probability that any random experiment is defined by a **probability triplet** $(\Omega, \mathcal{F}, \mathbb{P})$:

*   **$\Omega$ (Sample Space):** The set of all possible outcomes of a random experiment.
*   **$\mathcal{F}$ (Event Space):** A $\sigma$-algebra, which is a collection of subsets of $\Omega$ to which we can consistently assign probabilities.
*   **$\mathbb{P}$ (Probability Measure):** A function $\mathbb{P}: \mathcal{F} \rightarrow [0, 1]$ that assigns a probability to each event in our event space, satisfying the Kolmogorov axioms.

Because the abstract sample space $\Omega$ is often mathematically unwieldy to work with directly, we define a mapping called a **Random Variable** $X$:
$$X: \Omega \rightarrow \mathbb{R}^d$$

This mapping translates abstract outcomes into concrete, $d$-dimensional real numbers. Crucially, the random variable $X$ induces a **pushforward measure** (or **induced measure**) on $\mathbb{R}^d$. This induced measure is what we commonly refer to as the **distribution function** (or Cumulative Distribution Function, CDF):
$$P_X(a) = \mathbb{P}\left(X^{-1}((-\infty, a])\right) = \mathbb{P}\left(\{\omega \in \Omega \mid X(\omega) \leq a\}\right)$$

### Why do we focus on subsets of the form $(-\infty, a]$?
Any subset of real numbers $\mathbb{R}$ can be constructed using countable set operations (unions, intersections, complements) of these semi-infinite intervals. This brings us to a fundamental concept: the **Borel $\sigma$-algebra**.

---

For the machine learning problems we are discussing, is this Borel $\sigma$-algebra defined on $(-\infty, \infty)$, or is it always restricted to $[0, 1]$?”*

It is the smallest $\sigma$-algebra that contains all open subsets of $\mathbb{R}$.

---

### Density Functions vs. Distribution Functions
While the distribution function (denoted by the script double-lined $\mathbb{P}$ or $P_X$) represents actual probabilities, we often prefer to work with its derivative: the **probability density function** (PDF, denoted by lowercase $p_X$). 

Evaluating a continuous density function at a specific point $\hat{x}$ does **not** give a probability (indeed, the probability of a continuous random variable taking any exact single value is precisely zero). Rather, $p_X(\hat{x})$ represents the **likelihood density** at that point. To obtain a valid probability, we must integrate the density over a range:
$$\mathbb{P}(a \leq X \leq b) = \left. P_X(x) \right|_a^b = \int_{a}^{b} p_X(x) \, dx$$

## 2. The Core Machine Learning Settings

In machine learning, we are typically presented with one of two primary datasets:

### A. Unsupervised Learning Setting
We are given a dataset consisting only of inputs:
$$D = \{x_1, x_2, \dots, x_n\}$$
where each data point $x_i \in \mathbb{R}^d$ is a sample. For instance, in an image generation task, each $x_i$ might be a flattened vector of pixel values (e.g., $x_i \in \mathbb{R}^{60,000}$). Mathematically, we view each $x_i$ as an element drawn from the range space of an underlying random variable $X$.

### B. Supervised Learning Setting
We are given a dataset of input-output pairs:
$$D = \{(x_1, y_1), (x_2, y_2), \dots, (x_n, y_n)\}$$
where $x_i \in \mathbb{R}^d$ represents the input features (e.g., an MNIST image of handwritten digits where $d = 28 \times 28 = 784$), and $y_i$ represents the target label (e.g., $y_i \in \{0, 1, \dots, 9\}$). Here, the pairs are sampled from a **joint distribution** $P_{XY}$ induced by two random variables $X$ and $Y$ mapping from a shared sample space $\Omega$.

Regardless of the setting, we arrive at the **Central Problem of Machine Learning & Statistics**:
> **Given a finite set of samples drawn from a distribution, how do we estimate the underlying, unknown distribution?**

If we can estimate this distribution, we can perform two critical operations: **Prediction** and **Sampling**.

---

## 3. Discriminative Modeling and the Anatomy of "Prediction"

In supervised or **discriminative machine learning**, our primary goal is prediction. Mathematically, what does it mean to "predict"? 

Let's define our terms precisely.

### Defining "Likelihood"
The **likelihood** of a point $\hat{x}$ under a candidate distribution is defined as the value of the probability density function (or probability mass function, in the discrete case) evaluated at that point:
$$L(\hat{x}) = p_X(\hat{x})$$

### Defining "Prediction at $\hat{x}$"
Prediction at a specific, unseen input point $\hat{x}$ is defined as evaluating the **conditional density function** of the target variable $Y$ given the feature variable $X$:
$$\text{Prediction}(\hat{x}) = p_{Y \mid X}(y \mid X = \hat{x})$$

*Notation Note:* In this course, we use subscripts (e.g., $Y \mid X$) to denote the random variables, while the variables inside the parentheses (e.g., $y \mid x$) denote the specific values at which those functions are evaluated.

---

### 🙋‍♂️ Student Doubt: Visualizing the Conditional Random Variable
> **Student (Vivek):** *“Is there a way we can intuitively visualize the conditional random variable $Y \mid X$?”*
>
> **Professor's Answer:** Think of it as two random experiments conducted in tandem. In the first, we observe an input image $X$. In the second, we assign a label $Y$. Because they originate from a shared sample space, they possess a joint distribution $P_{XY}$. The conditional distribution is a slice of this joint space. Given that a specific event has occurred in the input space—namely, that we have observed a specific image $X = \hat{x}$—we look at the resulting probability distribution of the labels $Y$ over that restricted slice.

---

### 🙋‍♂️ Student Doubt: Why Density Functions over Distribution Functions?
> **Student (Raghavendra):** *“Is there a particular reason why we define the likelihood using the density function $p_X(x)$ rather than the cumulative distribution function $P_X(x)$?”*
>
> **Professor's Answer:** Density functions are significantly easier to work with analytically and computationally. While we can mathematically map one to the other, density functions allow us to easily leverage powerful tools like Kullback-Leibler (KL) divergence, score-based objectives, and autoregressive formulations. Furthermore, we intuitively remember the algebraic forms of densities (like the bell curve of a Gaussian or the flat line of a Uniform distribution), whereas their cumulative distribution functions can be mathematically inconvenient to write down or integrate.

---

### Concrete Example: Image Classification
Suppose we have a dataset of $100 \times 100$ pixel images.
*   The input variable $X$ maps to a high-dimensional space: $X \in \mathbb{R}^{10,000}$ (since $100 \times 100 = 10,000$ pixels).
*   The label variable $Y$ is discrete, representing one of $K$ classes: $Y \in \{0, 1, \dots, K\}$.

If a student asks, *"What does the prediction at an unseen image $\hat{x}$ output?"*, we can trace the interactive dialogue from the lecture:

*   *Argmax of the conditional density?* No, that is a decision rule applied *after* we get the prediction.
*   *A single label?* No, the prediction itself is not a single number.
*   *The output is the entire conditional density function!* 

Because $Y$ is discrete, the conditional density $p_{Y \mid X}(y \mid X = \hat{x})$ is a **probability mass function** consisting of $K + 1$ discrete values:
$$\left[ p_{Y|X}(0 \mid \hat{x}), \, p_{Y|X}(1 \mid \hat{x}), \, \dots, \, p_{Y|X}(K \mid \hat{x}) \right]$$

We can visualize this output as a bar chart containing $K+1$ bars, where the height of each bar represents the likelihood of that label given the image $\hat{x}$. 

```
Likelihood
  ^
  |      __
  |     |  |
  |  __ |  |     __
  | |  ||  | ...|  |
  | |_x||__|____|__|
  +-------------------> Labels (0 to K)
```

In typical application scenarios, the user wants a single classification decision. To make this decision, we apply a decision rule—most commonly, taking the **maximum a posteriori (MAP)** estimate, which is the class label that maximizes this likelihood:
$$y^* = \arg\max_{y \in \{0, \dots, K\}} p_{Y \mid X}(y \mid \hat{x})$$

---

### 🙋‍♂️ Student Doubt: The Other Way Around — Class-Conditional Density
> **Student (Srinath):** *“Is the conditional distribution in the other direction, $p(X \mid Y)$, also important? Does it have real-world significance?”*
>
> **Professor's Answer:** Yes, it has immense significance! The density $p(X \mid Y)$ is known as the **class-conditional density** (or the generative likelihood). It represents the probability density of generating an input $X$ given a specific class label $Y$. This is the cornerstone of generative classifiers (like Naive Bayes or Linear Discriminant Analysis) and forms the basis for conditional generative modeling, where we prompt a model to generate a specific type of data.

---

### Classification vs. Regression
We can unify supervised learning tasks under this conditional density estimation framework based on the nature of the target variable $Y$:

1.  **Classification:** If $Y$ is a **discrete** random variable, the task is classification. Our goal is to estimate a conditional probability mass function.
2.  **Regression:** If $Y$ is a **continuous** random variable (e.g., $Y \in \mathbb{R}^k$), the task is regression. Our goal is to estimate a continuous conditional probability density function.

---

## 4. Generative Modeling: The Art of Sampling

In unsupervised learning or **generative modeling**, we do not have target labels $Y$. We only have a dataset of inputs $D = \{x_1, \dots, x_n\} \sim P_X$. 

The goal of generative modeling is two-fold:
1.  **Estimate** the underlying unknown density $P_X$.
2.  **Learn to sample** from this estimated distribution.

### What is "Sampling"?
Mathematically, **sampling** is the process of implicitly running the underlying random trial/experiment corresponding to the sample space, such that the resulting points in our range space respect the estimated distribution.

If we train a generative model on the MNIST dataset (handwritten digits), sampling from this model must yield images of realistic handwritten digits. It should not yield images of human faces, landscapes, or uniform random noise. This is because the sampling process must strictly respect the high-density regions of the estimated distribution $P_X$.

```
 MNIST Density Space (Conceptual)
  ^
  |     /\      /\
  |    /  \    /  \      <-- High Density (Digits 0-9)
  |___/____\__/____\___  <-- Low Density (Noise / Faces)
  +---------------------> Image Space
```

There are many different generative architectures available today, including:
*   **Autoregressive Models (e.g., GPT series)**
*   **Generative Adversarial Networks (GANs)**
*   **Variational Autoencoders (VAEs)**
*   **Diffusion / Score-Based Models**
*   **Flow-Based Models**

Why do so many models exist? Because "all models are wrong, but some are useful." Each architecture represents a different mathematical approach to parameterizing the density $P_X$ and a different algorithmic mechanism for sampling from it.

---

### 🙋‍♂️ Student Doubt: Assuring the Source of Our Data
> **Student (Kartik):** *“Since we do not know the true distribution $P_X$, how can we be certain that our training samples were actually drawn from that specific distribution?”*
>
> **Professor's Answer:** This brings us to the most fundamental assumption in machine learning and statistics: the **I.I.D. (Independent and Identically Distributed) assumption**. We mathematically assume that our dataset $D = \{x_i\}_{i=1}^n$ consists of samples drawn independently from the exact same underlying distribution $P_X$. If this assumption is violated—such as in a **covariate shift** or **distribution shift** scenario where the test data comes from a different distribution than the training data—our models will inevitably perform poorly. 

---

### 🙋‍♂️ Student Doubt: What About Outliers?
> **Student (Aditya):** *“How do outliers fit into this assumption? Do we assume that our dataset contains no outliers?”*
>
> **Professor's Answer:** An outlier does not necessarily violate the I.I.D. assumption. Even if a data point appears highly unusual, it can still be generated by the same distribution $P_X$. It simply represents a sample drawn from the far **tails** of the distribution, where the density is extremely low. It is still a valid sample from $P_X$, just one with a very low likelihood.

---

## Unsupervised Learning vs. Generative Modeling
It is important to note that while all generative models are unsupervised, **not all unsupervised learning is generative**. 

Consider the difference between two classic clustering algorithms:
*   **K-Means Clustering:** An unsupervised algorithm that partitions data into clusters, but does not estimate a probability density function. Thus, you cannot sample new, synthetic data points from a trained K-Means model (non-generative).
*   **Gaussian Mixture Models (GMM):** An unsupervised algorithm that explicitly models the data as a mixture of Gaussian densities. Because GMMs estimate the density function $p_X(x)$, they are generative models, and you can easily sample new data points from them.

---

## Summary of the Modeling Landscape

| Modeling Type | Data Input | Mathematical Goal | Primary Objective |
| :--- | :--- | :--- | :--- |
| **Discriminative / Supervised** | Pairs $(x_i, y_i) \sim P_{XY}$ | Estimate conditional density $p_{Y \mid X}(y \mid x)$ | **Prediction** (Classification/Regression) |
| **Generative / Unsupervised** | Singletons $x_i \sim P_X$ | Estimate marginal density $p_X(x)$ and learn mapping to sample | **Sampling** (Synthesizing new data) |

Ultimately, whether we are building a classifier to predict a discrete label or a generative model to synthesize realistic images, we are trying to estimate an unknown probability density function from finite observations. The rest of this course will focus on the diverse family of estimators we use to solve this exact problem.


# Comprehensive Lecture Notes: Foundations of Generative Modeling and Divergence Minimization

In machine learning, models are broadly categorized into two paradigms depending on how they treat the underlying data distribution: **Discriminative Modeling** and **Generative Modeling**. This lecture explores the fundamental mathematical differences between these two approaches, defines the mechanics of the sampling process, and establishes a standardized recipe for training generative models using **Divergence Minimization**.

---

## 1. Discriminative vs. Generative Modeling

To understand generative modeling, it is helpful to first contrast it with the more common discriminative framework.

```
                  +-----------------------------------------+
                  |               Input Data D              |
                  +-----------------------------------------+
                                       |
                  +--------------------+--------------------+
                  |                                         |
                  v                                         v
     +--------------------------+              +--------------------------+
     |  Discriminative Path     |              |     Generative Path      |
     +--------------------------+              +--------------------------+
     | • Data: (x_i, y_i)       |              | • Data: {x_i} (no labels)|
     | • Goal: Estimate p(y|x)  |              | • Goal: Estimate p_x(x)  |
     | • Task: Classify/Regress |              | • Task: Sample new data  |
     +--------------------------+              +--------------------------+
```

### Discriminative Modeling
In discriminative modeling, we are given a dataset of supervised pairs:
$$D = \{(x_i, y_i)\}_{i=1}^n$$
where these pairs are assumed to be drawn Independent and Identically Distributed (i.i.d.) from an unknown joint probability distribution $p_{XY}$. 

*   **Objective:** Our goal is to estimate the conditional probability distribution:
    $$p(y|x)$$
*   **Context:** If $y$ is discrete ($y \in \{1, 2, \dots, k\}$), the task is **classification**. If $y$ is continuous ($y \in \mathbb{R}$), the task is **regression**.
*   **Characteristics:** Discriminative models do not require an explicit sampling mechanism; they simply map an input $x$ to a conditional distribution over $y$.

---

### Generative Modeling
In generative modeling, the setup is unsupervised. We are given a dataset containing only the features:
$$D = \{x_i\}_{i=1}^n$$
drawn i.i.d. from an unknown data distribution $p_x$.

*   **Objective:** We want to:
    1.  Estimate the underlying density function $p_x(x)$.
    2.  Learn how to **sample** new, unseen data points from this estimated distribution.
*   **Characteristics:** Unlike discriminative models, a generative model must possess an explicit sampling process to generate new instances that look like they were drawn from $p_x$.

---

## 2. What Exactly is "Sampling"?

To sample from a distribution means to **implicitly run a random trial corresponding to the underlying sample space**. 

Mathematically, this random trial yields a specific outcome. When we sample, this outcome corresponds to a point within the range space of the random variable, and the frequency of these points over many trials must strictly respect the underlying probability distribution.

---

> **Student (Sushil):** *"In both discriminative and generative cases, we get the density function. Why can't we just get the cumulative distribution function (CDF) from that?"*

**Instructor's Clarification:** We certainly can compute the distribution function (CDF) from the density function (PDF) via integration. However, in most practical machine learning applications, having access to the density function itself is sufficient. The more challenging and important task in generative modeling is not just knowing the density, but being able to *sample* from it effectively, especially when dealing with high-dimensional spaces (such as images).

### Student Doubt 3: Do generative models associate data with labels?
> **Student (Manisha):** *"So, in the first step of generative modeling, finding the underlying distribution is what tells us which class is linked to which label?"*

**Instructor's Clarification:** **No.** This is a common point of confusion. In the basic formulation of generative modeling:
$$D = \{x_i\}_{i=1}^n$$
there are **no labels** ($y$) at all. We are not trying to find mapping relationships between classes and labels. Instead, we are solely estimating the probability density $p_x(x)$. This tells us the likelihood of a particular image (or data point) existing under the distribution, regardless of its class name.

#### What about Conditional Generation?
If we do have labels, we can extend generative modeling to **Conditional Generation**:
*   Instead of modeling $p(x)$, we model the conditional distribution $p(x|y)$ (the probability of generating data $x$ given a specific condition/prompt $y$).
*   To do this, we need pairs $(x_i, y_i)$ during training.
*   **Real-world Example:** This is exactly how tools like ChatGPT work. Given a prompt $y$, the model samples from $p(x|y)$ to generate the next sequence of words $x$.
*   However, in standard, unconditional generative modeling, we only focus on the unsupervised density $p(x)$.

## 3. The Core Question of Generative Modeling

Given that we only have a finite set of data points $D$ drawn from an unknown distribution, how do we estimate the underlying density function $p_x(x)$?

To solve this, modern machine learning relies on a framework called **Divergence Minimization**.

---

## 4. The Standard Recipe: Divergence Minimization

The process of estimating an unknown distribution from data using divergence minimization can be broken down into three concrete steps:

```
+--------------------------------------------------------------------------+
|                       Divergence Minimization Recipe                      |
+--------------------------------------------------------------------------+
|                                                                          |
|  Step 1: Assume a Parametric Form                                        |
|          Define a model family p_θ(x) parametrized by θ.                  |
|                                                                          |
|  Step 2: Define a Divergence Metric                                      |
|          Establish a distance D(p_x || p_θ) to compare distributions.     |
|                                                                          |
|  Step 3: Optimize Parameters (Training)                                  |
|          Find θ* = argmin D(p_x || p_θ) using gradient descent.              |
|                                                                          |
+--------------------------------------------------------------------------+
```

### Step A: Assume a Parametric Form (The "Model")
First, we assume a parametric family of distributions to represent our estimate of the unknown density. We denote this parametric family as:
$$p_\theta(x)$$
where $\theta$ represents the set of parameters we need to learn. In machine learning, $p_\theta$ is referred to as the **Model**.

#### Example 1: Classical Parametric Form (Gaussian)
We can assume $p_\theta$ is a multivariate Gaussian distribution:
$$p_\theta(x) = \mathcal{N}(x; \mu, \Sigma)$$
In this case, the parameters we need to estimate are the mean vector and the covariance matrix:
$$\theta = \{\mu, \Sigma\}$$

#### Example 2: Modern Deep Parametric Form (Deep Generative Model)
We can define our model such that the target variable $x$ is produced by passing a simple, easily-sampled latent variable $z$ through a neural network:
$$x = g_\theta(z) \quad \text{where} \quad z \sim \mathcal{N}(0, I)$$
Here, $g_\theta$ is a neural network (e.g., a Transformer, CNN, or MLP) and $\theta$ represents the weights and biases of this network. The resulting distribution of $x$ is our parametric model $p_\theta(x)$.

---

### Student Doubt 4: Understanding the neural network generator setup
> **Student (Sanchit):** *"What are $g_\theta$ and $z$ in this modern setup?"*

**Instructor's Clarification:** 
*   **$z$** is a random variable drawn from a simple, known distribution (typically a standard normal distribution $\mathcal{N}(0, I)$). Because it is simple, we can easily generate samples of $z$ on a computer.
*   **$g_\theta(\cdot)$** is a highly expressive neural network parametrized by weights $\theta$. 
*   The neural network takes the simple noise vector $z$ as input and transforms it into a complex data point $x$ (such as an image). 
*   By modifying the weights $\theta$ of the network, we change the shape of the resulting output distribution $p_\theta(x)$.

---

### Student Doubt 5: Why do we use complex parametric forms?
> **Student (Karthik):** *"Could you explain the parametric form with a simpler example? Why do we need neural networks instead of simple distributions?"*

**Instructor's Clarification:**
Let's look at the geometry of different distributions:
*   A single Gaussian distribution $\mathcal{N}(\mu, \Sigma)$ is **unimodal**—it has only one peak. 
*   If our real-world data (such as the MNIST handwritten digits dataset) has multiple clusters (peaks for '0', '1', '2', etc.), a single Gaussian is a poor model assumption. No choice of $\mu$ and $\Sigma$ will allow a single Gaussian to fit ten distinct peaks.
*   This is why we use deep neural networks. According to the **Universal Approximation Theorem**, deep neural networks can approximate incredibly complex, highly non-linear, and multi-modal mathematical functions. 
*   By passing a simple Gaussian $z$ through a neural network $g_\theta$, we can warp and bend that simple distribution into an incredibly complex, multi-modal target distribution $p_\theta(x)$ that can match our real data.

---

### Step B: Define a Distance or Divergence Metric
Next, we need a mathematical tool to measure how close our model's distribution $p_\theta$ is to the true, unknown data distribution $p_x$. We define a divergence metric:
$$D(p_x \parallel p_\theta)$$
This metric output tells us "how far" our model is from the truth. Ideally, if $p_\theta = p_x$, then $D(p_x \parallel p_\theta) = 0$.

Common choices of divergence metrics in generative modeling include:
1.  **$f$-divergences** (e.g., Kullback-Leibler (KL) Divergence, Jensen-Shannon (JS) Divergence)
2.  **Wasserstein Distance** (Optimal Transport)
3.  **Maximum Mean Discrepancy (MMD)**

---

### Student Doubt 6: Can we always evaluate the divergence metric?
> **Student (Lokesh Kumar):** *"Will we always be able to evaluate this divergence metric in practice?"*

**Instructor's Clarification:** **No, not directly.** This is the central mathematical challenge of generative modeling. 
The divergence formula $D(p_x \parallel p_\theta)$ explicitly requires knowing the true density $p_x$. But $p_x$ is unknown—we only have a finite set of samples $D$ drawn from it. 

Because we cannot write down $p_x$ analytically, we cannot compute the exact divergence. Instead, we must use mathematical approximations, variational lower bounds (like the ELBO in Variational Autoencoders), or adversarial games (like the discriminator in GANs) to minimize the divergence implicitly using only our data samples.

---

### Step C: Parameter Optimization (The "Training" Phase)
Once we have defined our model $p_\theta$ and our divergence metric $D$, we search for the optimal set of parameters $\theta^*$ that minimizes this divergence:
$$\theta^* = \arg\min_\theta D(p_x \parallel p_\theta)$$

In deep learning, we solve this optimization problem using gradient-based optimization algorithms (such as Adam or SGD) alongside backpropagation. The resulting optimized distribution $p_{\theta^*}$ serves as our final estimate of the true data distribution $p_x$.

---

### Student Doubt 7: Choice of the latent distribution
> **Student (Raghavendra):** *"Is the choice of the latent distribution $z$ also a model parameter that we optimize?"*

**Instructor's Clarification:** No, the distribution of $z$ (e.g., $z \sim \mathcal{N}(0, I)$) is a design choice that remains fixed. We do not optimize the parameters of $z$. Instead, we keep the source distribution simple and static, and we rely entirely on the neural network $g_\theta$ to learn how to map this simple space into the complex target data space.

---

### Student Doubt 8: Why minimize divergence if we can find the real $p_x$?
> **Student (Rajat):** *"If we have mathematical tricks to eventually find the real $p_x$, why do we need to bother with minimizing a divergence metric at all?"*

**Instructor's Clarification:** The "tricks" we use do not magically reveal $p_x$ to us. We never actually compute or observe the true analytical form of $p_x$. The only way we can verify if our model $p_\theta$ is improving is by measuring its discrepancy from the data samples. Minimizing the divergence is the mathematically principled way of forcing $p_\theta$ to match $p_x$ as closely as possible using only the empirical samples we have.

---

## 5. Summary of the Generative Modeling Landscape

Almost every generative model in modern machine learning fits into this standardized recipe. The main differences between them lie in the specific choices they make for the model architecture, the divergence metric, and the optimization strategy:

| Model Type | Parametric Model ($p_\theta$) | Divergence Metric ($D$) | Key Characteristic |
| :--- | :--- | :--- | :--- |
| **Variational Autoencoder (VAE)** | Latent variable model with an encoder-decoder network | KL-Divergence (optimized via the Evidence Lower Bound / ELBO) | Optimizes a tractable lower bound on the data likelihood. |
| **Generative Adversarial Network (GAN)** | Implicit generator network $g_\theta(z)$ | Jensen-Shannon Divergence (implicitly minimized via an adversarial game) | Uses a secondary "Discriminator" network to guide the generator. |

# Lecture Notes: Measuring the Distance Between Probability Distributions — From Shannon Information to KL Divergence

In deep generative modeling—whether we are designing Variational Autoencoders (VAEs) or framing objective functions for Generative Adversarial Networks (GANs)—we constantly face a fundamental mathematical challenge [160:02]. This post details the journey from the basic axioms of information theory to the formulation of **Kullback-Leibler (KL) Divergence**, providing a complete breakdown of the lecture, student interactions, and key mathematical derivations.

---

## The Core Optimization Question

At the heart of generative modeling lies a simple question [160:25]:

$$\text{\textbf{Given a pair of density functions, how do we measure the distance or divergence between them?}}$$

To train a model (like a parameterized density $P_\theta(x)$) to match a target true data distribution ($P_x(x)$), we must quantify how "far" or "close" they are [180:10, 188:01]. To build a robust metric for this, we must first lay down the foundations of **Information Theory** [161:40].

---

## 1. Defining "Information" or "Surprisal" ($I(A)$)

Let there be an event $A$ within a set of possible events $\mathcal{F}$ (i.e., $A \in \mathcal{F}$) [161:01]. We want to define a measure, $I(A)$, that quantifies the **amount of information** or **surprisal** associated with the occurrence of event $A$ [161:01, 166:12]. 

### Intuitive Properties of Information
For any valid information measure $I(A)$, we expect it to satisfy the following natural behaviors:
1. **High Surprisal for Rare Events:** $I(A)$ should be **high** for less-probable events [162:17].
2. **Low Surprisal for Common Events:** $I(A)$ should be **low** for highly probable events [162:30].

> **The Sun Rising Example:** 
> * If someone tells you, *"The sun will rise in the West tomorrow,"* this is an extremely rare (impossible) event [162:50]. It carries an immense amount of "information" or shock value (high surprisal) [162:53].
> * Conversely, if someone says, *"The sun will rise in the East tomorrow,"* the probability is virtually $1$ [162:57]. This statement carries essentially zero new information (low surprisal) [163:00].

### Asymptotic Edge Cases
To translate this intuition into mathematics, we define the extreme limits [163:23]:
* **Certain Events:** For the entire sample space $\Omega$ (where $P(\Omega) = 1$), the event is guaranteed to happen. Therefore, it carries zero surprisal:
  
  $$I(\Omega) = 0 \quad [164:15]$$

* **Impossible Events:** For the null set $\emptyset$ (where $P(\emptyset) = 0$), the event cannot happen. If it somehow did, it would represent infinite surprisal:
  
  $$I(\emptyset) = \infty \quad [164:19]$$

*(Note: During the lecture, the instructor initially made a minor slip on the board by writing $I(\Omega) = \infty$ and $I(\emptyset) = 0$, but corrected it immediately after analyzing the probabilities [163:35]).*

---

### 🙋‍♂️ Doubt Corner 1: Why is $I(\emptyset) = \infty$, and why do we define $I(A) = -\log P(A)$?
**Student Question:** *"I didn't quite get why the information associated with the null set is infinity, and how Claude Shannon arrived at the negative logarithm formula."* [172:15]

**Instructor's Explanation:** 
Historically, Claude Shannon was looking for a way to mathematically define information for engineering and communication channels [166:01]. 

* **Monotonicity:** Information must be a monotonically decreasing function of probability [162:17]. As $P(A) \to 0$, surprisal must shoot up to infinity ($I(A) \to \infty$) [164:19].
* **Additivity:** If you have two completely independent events, say $A$ and $B$, the joint information of both happening should simply be the sum of their individual informations: $I(A \cap B) = I(A) + I(B)$ [164:51]. 
* **The Logarithmic Solution:** Since independent probabilities multiply ($P(A \cap B) = P(A) \cdot P(B)$), we need a mathematical function that transforms multiplication into addition [175:47]. The logarithm is the unique continuous function that satisfies:
  
  $$\log(x \cdot y) = \log(x) + \log(y) \quad [175:58]$$

By introducing a negative sign to keep the value positive (since probabilities are $\leq 1$), we arrive at Shannon's definition of self-information [166:14]:

$$I(A) = -\log P(A) \quad [166:14]$$

---

## 2. Axiomatic Properties & Independent Events

To ensure our information measure behaves cleanly, we establish how it acts over joint events. If two events $A$ and $B$ are **mutually independent** (meaning $P(A \cap B) = P(A) \cdot P(B)$), the joint information of both occurring is additive [164:51]:

$$I(A \cap B) = I(A) + I(B) \quad \text{if } A, B \text{ are independent} \quad [165:10]$$

---

### 🙋‍♂️ Doubt Corner 2: Disjoint vs. Independent and Edge Cases
**Student (Sanket) Question:** *"If we write $I(A \cup B) = I(A) + I(B)$ for disjoint events where $A \cap B = \emptyset$, what happens if we take $A \cup \emptyset$? Since $A \cap \emptyset = \emptyset$, this property would mean $I(A \cup \emptyset) = I(A) + I(\emptyset) = I(A) + \infty = \infty$. But $A \cup \emptyset = A$, so the left side is just $I(A)$. This doesn't seem to hold."* [177:01]

**Instructor's Explanation:** 
*"That is an excellent catch! You are pointing out an edge-case discrepancy when dealing with empty sets."* To keep the framework mathematically consistent, we explicitly restrict this additive union notation to non-empty events [177:49]:

$$I(A \cup B) = I(A) + I(B) \quad \text{for } A, B \neq \emptyset \quad \text{and } A \cap B = \emptyset \quad [177:52]$$

**Student (Aditya) Question:** *"What if $B = A^c$ (the complement of $A$)? Since they are disjoint, their union is the entire sample space $\Omega$. Does the information add up to zero?"* [180:05]

**Instructor's Explanation:** 
Yes, by definition, the total information of the system (the union of an event and its complement) yields $I(\Omega) = 0$, reflecting that once you observe the entire space, there is zero remaining uncertainty [181:20].

---

## 3. Quantifying Information Across a Distribution: Entropy ($H(P)$)

Self-information $I(A)$ tells us the surprisal of a *single* event [174:11]. What if we want to quantify the overall average uncertainty or information inherent to an **entire probability distribution** $P$? [168:09, 181:15]

To do this, we take the expected value (weighted average) of the self-information over all possible outcomes $x_i$ in our distribution [168:37]:

$$H(P) = E_{X \sim P}[I(X)] \quad [169:36]$$

For a discrete distribution [169:13]:

$$H(P) = \sum_{i=1}^N P(x_i) \cdot \left[ -\log P(x_i) \right] = -\sum_{i=1}^N P(x_i) \log P(x_i) \quad [169:46, 183:40]$$

This expected value is famously known as the **Shannon Entropy** of the distribution $P$ [178:44, 184:44].

---

### 🙋‍♂️ Doubt Corner 3: Capital $P$ vs. Small $p$
**Student (Sachin) Question:** *"In the entropy summation, should we write capital $P$ or small $p$? I recall small $p$ was reserved for continuous probability densities."* [161:16]

**Instructor's Explanation:** 
Because we are illustrating these core principles using a **discrete distribution** for ease of understanding, we are using the Probability Mass Function (PMF), which outputs actual probability values (hence capital $P$) [169:10, 169:20]. For continuous distributions, we would transition to integration over continuous Probability Density Functions (PDFs, small $p$) [169:23].

---

## 4. Comparing Two Distributions: Cross-Entropy ($H(P, Q)$)

Suppose we have two density/mass functions [180:30]:
* $P(x)$: The **true** distribution of our data [180:35].
* $Q(x)$: An **assumed** or **model** distribution that we are using to approximate $P(x)$ [180:35].

What happens if the actual events are drawn from the true distribution $P$, but we calculate our surprisal (information) based on our model's beliefs $Q$? [181:15]

This expectation is defined as **Cross-Entropy** ($H(P, Q)$) [182:25]:

$$H(P, Q) = E_{X \sim P}[-\log Q(X)] = -\sum_{i=1}^N P(x_i) \log Q(x_i) \quad [181:15, 182:28]$$

> **Intuitive Interpretation:** Cross-entropy represents the average length of the message needed to transmit events from the true distribution $P$ if we use an encoding scheme optimized for our assumed model distribution $Q$ [181:48].

---

### 🙋‍♂️ Doubt Corner 4: The Order of Terms in Subtraction
**Student Question:** *"When we look at cross-entropy, why is the first term weighted by $P(x_i)$ and not $Q(x_i)$? And when we subtract them to find the difference, shouldn't we subtract $H(Q)$ instead of $H(P)$? If we subtract $H(P, Q) - H(P)$, could we end up with a negative value?"* [183:32, 184:20]

**Instructor's Explanation:** 
Let’s break down the math to see why the order must be $H(P, Q) - H(P)$ [184:43]:

* We weight by $P(x_i)$ because the samples are *actually* occurring according to the true world $P$ [181:15]. 
* To measure the "extra" penalty of using the incorrect distribution $Q$ to model $P$, we subtract the minimum possible average surprisal (which is the true entropy $H(P)$) from our actual average surprisal ($H(P, Q)$) [183:01]:

$$\text{Extra Information Penalty} = H(P, Q) - H(P) \quad [182:43]$$

Because $H(P, Q)$ represents coding with an imperfect model, it will *always* be greater than or equal to coding with the true distribution, $H(P)$ [187:34]. Thus, this difference is guaranteed to be non-negative ($\geq 0$), which brings us to KL Divergence [187:18].

---

## 5. Kullback-Leibler (KL) Divergence ($D_{KL}(P \parallel Q)$)

By expanding the "extra information penalty" formula, we can derive the explicit mathematical form of **KL Divergence** [186:27]:

$$D_{KL}(P \parallel Q) = H(P, Q) - H(P) \quad [182:43]$$

Substitute the definitions of Cross-Entropy and Entropy [184:50]:

$$D_{KL}(P \parallel Q) = \left( -\sum_{i=1}^N P(x_i) \log Q(x_i) \right) - \left( -\sum_{i=1}^N P(x_i) \log P(x_i) \right) \quad [185:02, 185:08]$$

$$D_{KL}(P \parallel Q) = -\sum_{i=1}^N P(x_i) \log Q(x_i) + \sum_{i=1}^N P(x_i) \log P(x_i) \quad [185:15]$$

Group the terms under a single summation [185:43]:

$$D_{KL}(P \parallel Q) = \sum_{i=1}^N P(x_i) \left[ \log P(x_i) - \log Q(x_i) \right] \quad [186:00]$$

Using the logarithmic identity $\log(a) - \log(b) = \log(\frac{a}{b})$, we arrive at the standard formula [185:53]:

$$D_{KL}(P \parallel Q) = \sum_{i=1}^N P(x_i) \log \frac{P(x_i)}{Q(x_i)} \quad [186:00, 186:51]$$

---

### Key Mathematical Properties of KL Divergence
1. **Non-negativity:**
   
   $$D_{KL}(P \parallel Q) \geq 0 \quad [187:18]$$
   
   *(You will prove in tutorials/exercises using Jensen's Inequality that this value can never drop below zero).*

2. **Identity of Indiscernibles:**
   
   $$D_{KL}(P \parallel Q) = 0 \iff P = Q \quad [187:19]$$
   
   The divergence is exactly zero if and only if the assumed distribution $Q$ matches the true distribution $P$ perfectly [187:25].

3. **Asymmetry:**
   
   $$D_{KL}(P \parallel Q) \neq D_{KL}(Q \parallel P)$$
   
   Because it is asymmetric, KL Divergence is **not a true distance metric** in the mathematical sense (which is why we refer to it as a *divergence* rather than a distance) [160:28, 161:34].

---

## Tying It Back to Generative Models

Why did we do all this? Returning to our target generative learning framework, we have some true data distribution $P_x(x)$ and our model $P_\theta(x)$ [180:10, 188:01]. 

To train our model, we construct our loss function directly around minimizing this KL Divergence [187:03]:

$$\theta^* = \arg\min_\theta D_{KL}(P_x \parallel P_\theta) \quad [178:00, 187:04]$$

By minimizing this objective, we are forcing our model's parameterized distribution $P_\theta$ to become closer to the true data distribution $P_x$ [180:10, 187:04].
